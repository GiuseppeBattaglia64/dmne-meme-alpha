CHAPTER 01

Institutional Architecture & Non-Custodial Model

DMNE Meme Alpha is an institutional quantitative algorithmic execution platform engineered specifically for Solana meme coin micro-liquidity markets. The system operates on a dual-speed decoupled paradigm separating sub-millisecond execution from asynchronous forensic intelligence.

⚡ SUB-MILLISECOND HOT-PATH (RUST)
Engineered in pure Rust with lock-free atomics, bounded rolling ring buffers, and Tokio async actors. Microstructure evaluations execute in under 5 microseconds, dispatching priority Jito bundles direct to Solana block builders.
🌊 COLD-PATH DATA LAKE (POSTGRESQL)
Every trade settlement, rejection snapshot, and tick trace is asynchronously ingested into PostgreSQL (dmne_quant). Ensures complete forensic fidelity without introducing synchronous database lock contention to the execution path.
Multi-Tenant Prop Model: Traders (e.g. Master Admin, Giuseppe, Giovanni) have isolated virtual sub-ledgers. Capital allocation operates on dynamic Fractional Kelly Sizing (4.5% to 8.5% NAV) across exactly 4 concurrent execution slots, guaranteeing strict capital preservation.
CHAPTER 02

Pre-Trade Filtration & Discovery Gates

Over 99.4% of candidate tokens are mathematically filtered before capital is exposed. Candidates must clear a cascade of quantitative gates:

1. Hawkes Self-Exciting Point Process Filter
Measures arrival time intervals in fractional Unix seconds (t ∈ ℝ). Calculates the self-excitation branching ratio (η = α / β). Robotic clocking and wash-trading are detected when η ≥ 1.25 with sample size N ≥ 5, triggering immediate rejection.
2. Genesis Guard & Slot 0 Anti-Sniper Cluster Detection
Surveils block 0 bundlers. Rejects any token where block 0 transactions bundle > 25.0% of circulating supply or multi-wallet clusters share identical Jito bribe tip accounts. Protects against coordinated sniper dumps.
3. Cumulative Volume Delta (CVD) Orderflow Gate
Maintains a 60-second rolling taker volume window. Requires taker buy pressure ratio ≥ +15.0% ((BuyVol - SellVol) / TotalVol ≥ 0.15) prior to queue entry confirmation.
